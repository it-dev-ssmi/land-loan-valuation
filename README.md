# ລະບົບປະເມີນທີ່ດິນ → ວົງເງິນປ່ອຍກູ້ (Next.js + Supabase)

ພະນັກງານປ້ອນຂໍ້ມູນທີ່ດິນ → ເລືອກ **ແຂວງ / ເມືອງ / ບ້ານ / ປະເພດທາງ** →
ລະບົບ **ດຶງລາຄາ ແລະ % ຈາກຖານຂໍ້ມູນ** ມາຄຳນວນ ມູນຄ່າ ແລະ ວົງເງິນປ່ອຍກູ້ໃຫ້ອັດຕະໂນມັດ.
ຖ້າດິນມີ **ສິ່ງປຸກສ້າງ** ກໍຄຳນວນເພີ່ມ ແລ້ວ**ລວມ**ເປັນວົງເງິນສຸດທ້າຍ.

ລາຄາດິນ **ບໍ່ໄດ້ຝັງໃນໂຄ້ດ** — ຢູ່ຕາຕະລາງ `land_prices` (ຕໍ່ ບ້ານ × ປະເພດທາງ).
% ປ່ອຍກູ້ຂອງດິນ ຢູ່ຕາຕະລາງ `road_types`. ປ່ຽນໄດ້ຕະຫຼອດໂດຍບໍ່ຕ້ອງແກ້ໂຄ້ດ.

## ສູດຄຳນວນ
```
ມູນຄ່າດິນ          = ເນື້ອທີ່ດິນ × ລາຄາດິນ/ຕ.ມ.        ← land_prices (ບ້ານ × ປະເພດທາງ)
ວົງເງິນຈາກດິນ      = ມູນຄ່າດິນ × (road_type.ltv_pct / 100)
ມູນຄ່າສິ່ງປຸກສ້າງ   = ເນື້ອທີ່ × ລາຄາກໍ່ສ້າງ/ຕ.ມ. × ຄວາມສຳເລັດ% × ອາຍຸ%   ← ຕາມເອກະສານ
                     (ເຮືອນ 1,500,000 · ເຮືອນໄມ້ 500,000 /ຕ.ມ. · ຄວາມສຳເລັດ <50% = ບໍ່ປະເມີນ)
                     (ອາຍຸ: 1–3ປີ 80% · 3–10ປີ 60% · 10–15ປີ 40% · >15ປີ 20%)
ວົງເງິນຈາກສິ່ງປຸກສ້າງ = ມູນຄ່າ × (buildingType.ltv_pct / 100)
────────────────────────────────────────────────
ວົງເງິນປ່ອຍກູ້ລວມ   = ວົງເງິນຈາກດິນ + ວົງເງິນຈາກສິ່ງປຸກສ້າງ
```

**ຕົວຄູນພິເສດ (ຄູນສອງ):** ຕອນປະເມີນ ເລືອກ "ຄູນພິເສດ" ໄດ້ (ບໍ່ໃຊ້ / ດິນ / ສິ່ງປຸກສ້າງ / ທັງສອງ) —
ມັນຈະເອົາມູນຄ່າ ×ຕົວຄູນ (ຄ່າເລີ່ມຕົ້ນ 2) ກ່ອນຄິດ %. ຕົວຄູນແກ້ໄດ້ທີ່ `settings.extra_multiplier`.

**ຄ່າທຳນຽມ (ມາດຕາ 6):**
```
6.1 ຄ່າບໍລິການ   = ວົງເງິນກູ້ × (ວົງເງິນ ≤ 50,000,000 ? 1% : 0.5%)
6.2 ຄ່າລົງປະເມີນ = ໃນເມືອງ 300,000 ;
                   ຕ່າງເມືອງ ≤30km 400,000 / 31–80km 600,000 / 81km+ 800,000  (ຫຼາຍຕອນ → ໄກສຸດ)
ລວມຄ່າທຳນຽມ     = ຄ່າບໍລິການ + ຄ່າລົງປະເມີນ
```
ອັດຕາ/ຕົວເລກທັງໝົດແກ້ໄດ້ທີ່ຕາຕະລາງ `settings` (ຄີ `fee_*`) ຫຼື ແຖບ "ຄ່າທຳນຽມ" ໃນ admin.

**ຮູບໃບຕາດິນ/ຫຼັກຊັບ:** ຕອນປະເມີນ ພະນັກງານແນບຮູບໄດ້ຫຼາຍຮູບ → ອັບໂຫຼດຂຶ້ນ Supabase Storage
(bucket `title-docs`) ຕອນກົດບັນທຶກ, ເກັບລິ້ງໄວ້ທີ່ `valuations.title_doc_urls`.
ຕ້ອງລັນ `supabase/0003_storage.sql` ເທື່ອດຽວ (ສ້າງ bucket + policy).

**ວົງເງິນປ່ອຍຈິງ:** ພະນັກງານຄີ່ "ວົງເງິນປ່ອຍຈິງ" ເອງໄດ້ (ຍອດທີ່ປ່ອຍແທ້) — ຄ່າທຳນຽມຈະຄິດຈາກຍອດຈິງນີ້.
ຖ້າປ່ອຍວ່າງ = ຄິດຈາກວົງເງິນສູງສຸດ. (ເກັບທີ່ `valuations.actual_loan`)

## ຕິດຕັ້ງ
1. ສ້າງໂປຣເຈັກ Supabase → ເອົາ URL ແລະ anon key.
2. Supabase SQL Editor: ລັນ `supabase/0001_init.sql` ແລ້ວ `supabase/seed_land_prices.sql`.
3. ```
   cp .env.local.example .env.local   # ໃສ່ URL + anon key
   npm install && npm run dev
   ```
4. ເປີດ http://localhost:3000
